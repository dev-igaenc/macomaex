# AI 거래처 추천 및 분석 정책

## 거래 방향별 데이터 의미

### 구매처 찾기 (`trade_type=1`)

- 사용자 선택 항목: 의뢰사가 구매하려는 품목·서비스
- 추천 대상: 해당 품목·서비스를 공급할 가능성이 있는 기업
- 구매 가능 품목: 추천 기업으로부터 의뢰사가 구매할 수 있는 품목·서비스

### 판매처 찾기 (`trade_type=2`)

- 사용자 선택 항목: 의뢰사가 진입하려는 판매채널·거래처 유형
- 추천 대상: 선택한 판매채널·거래처 유형에 해당하는 기업
- 판매 가능 품목: 의뢰사가 추천 기업에 판매할 수 있는 실제 품목·서비스

판매처 찾기에서 선택한 `백화점`, `종합도매` 같은 값은 판매 가능 품목이 아니다. 이 값은 추천 대상 업종 필터와 판매채널 적합성 분석에 사용한다.

## 분석 컨텍스트

후속 단계에서 추천 목록, 상세 페이지, LLM 분석 요청이 동일한 선택 의도를 유지하도록 아래 값을 거래 컨텍스트로 관리한다.

- `trade_type`: 구매처 또는 판매처 방향
- `selected_target_keywords`: 사용자가 선택한 구매 품목 또는 판매채널·거래처 유형
- `selected_partner_bzc_cds`: 선택 항목에 연결된 추천 대상 업종코드
- `recommendation_mode`: 키워드 추천 또는 전체 추천
- `trace_id`: 추천 실행 추적 ID

키워드 조합은 중복을 제거하고 정렬한 뒤 동일 조합 여부를 판정한다.

## 리포트 캐시 및 크레딧 정책

리포트 캐시와 크레딧 차감 여부는 별도 키로 관리한다.

### 리포트 캐시

- 의뢰사 + 추천 기업 + 거래방향 + 정규화된 선택 키워드 조합을 기준으로 분리한다.
- 동일 기업이라도 선택 키워드 조합이 다르면 새로운 리포트를 생성한다.
- 동일 키워드 조합의 순서만 다른 경우에는 같은 리포트 캐시를 사용한다.

### 크레딧 차감

- 회원 + 의뢰사 + 추천 기업을 기준으로 정책 기간 내 한 번만 차감한다.
- 선택 키워드 조합이나 거래방향이 달라 새로운 리포트를 생성하더라도 추가 차감하지 않는다.
- 리포트 생성 실패 시 기존 환불 정책을 유지한다.

## 범용 태그 사용 원칙

- 실제 기업 품목과 업종 기반 추론값, 화면 표시용 범용 태그를 구분한다.
- `납품용역`, `B2B소재`, `산업부품` 같은 범용 태그는 카드 표시용 fallback일 수 있으나 LLM의 실제 거래 품목 근거로 사용하지 않는다.
- 실제 품목 정보가 없으면 임의 품목을 만들지 않고 정보 확인이 필요함을 안내한다.
